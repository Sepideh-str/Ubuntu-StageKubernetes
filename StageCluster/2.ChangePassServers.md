# Changing a Linux User Password

To change the password of the **current Linux user**, run:

```bash
passwd
```

The system asks for:

1. Current password
2. New password
3. Confirmation of the new password

### Change Another User's Password

If you have `sudo` privileges:

```bash
sudo passwd username
```

Example:

```bash
sudo passwd sepideh
```

This allows an administrator to set a new password for the specified user.
