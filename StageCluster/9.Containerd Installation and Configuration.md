# Containerd Installation and Configuration

Containerd is the container runtime used by Kubernetes to create and manage containers.

## 1. Configure Nexus Repository

Create the APT repository configuration:

```bash
sudo vi /etc/apt/sources.list.d/containerd.list
```

Add:

```text
deb [trusted=yes arch=amd64] https://repository.crouseco.com/repository/containerd-ubuntu-proxy resolute stable
```

Clean APT metadata and update:

```bash
sudo rm -rf /var/lib/apt/lists/*
sudo apt clean
sudo apt update
```

## 2. Install Containerd

Install `containerd.io`:

```bash
sudo apt install -y containerd.io
```

Verify the installation:

```bash
containerd --version
```

## 3. Generate Containerd Configuration

Create the configuration directory and generate the default configuration:

```bash
sudo mkdir -p /etc/containerd
sudo containerd config default | sudo tee /etc/containerd/config.toml > /dev/null
```

## 4. Enable Systemd Cgroup

Configure containerd to use the systemd cgroup driver:

```bash
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
```

Verify:

```bash
grep SystemdCgroup /etc/containerd/config.toml
```

Expected:

```text
SystemdCgroup = true
```

## 5. Configure Kubernetes Sandbox Image

Configure the Kubernetes pause image to use the internal container registry:


```text
vi /etc/containerd/config.toml
sandbox = 'repository.crouseco.com/k8s-proxy/pause:3.10.2'
```

Verify:

```bash
grep -n "sandbox =" /etc/containerd/config.toml
```

## 6. Enable and Start Containerd

```bash
sudo systemctl daemon-reload
sudo systemctl enable containerd
sudo systemctl restart containerd
```

Verify the service:

```bash
sudo systemctl status containerd
```

Expected status:

```text
Active: active (running)
```

## Verification

At the end of this step:

* `containerd.io` is installed.
* Containerd uses `SystemdCgroup`.
* Kubernetes uses the internal pause image.
* Containerd is enabled and running.
