# Kubernetes Package Installation

Install Kubernetes components using the internal Nexus APT repository.

## 1. Configure Kubernetes Repository

Create the APT repository configuration:

```bash
sudo vi /etc/apt/sources.list.d/kubernetes.list
```

Add:

```text
deb [trusted=yes arch=amd64] https://repository.crouseco.com/repository/k8s-pack-proxy-ubuntu/ /
```
apt 
Update the package metadata:

```bash
sudo apt update
```

## 2. Check Available Kubernetes Version

```bash
apt-cache policy kubeadm kubelet kubectl
```

Verify that the required version is available.

## 3. Install Kubernetes Components

Install the selected Kubernetes version:

```bash
sudo apt install -y kubeadm=1.36.4-1.1 kubelet=1.36.4-1.1 kubectl=1.36.4-1.1
```

## 4. Verify Installation

```bash
kubeadm version
kubelet --version
kubectl version --client
```

Expected version:

```text
v1.36.4
```

## 5. Hold Kubernetes Packages

Prevent automatic upgrades:

```bash
sudo apt-mark hold kubeadm kubelet kubectl
```

Verify:

```bash
apt-mark showhold
```

Expected:

```text
kubeadm
kubelet
kubectl
```

## Result

The node now has the required Kubernetes components installed and pinned to **Kubernetes v1.36.4**:

* `kubeadm` — cluster initialization and node joining
* `kubelet` — Kubernetes node agent
* `kubectl` — Kubernetes command-line client

The node is now ready for the cluster initialization phase.
