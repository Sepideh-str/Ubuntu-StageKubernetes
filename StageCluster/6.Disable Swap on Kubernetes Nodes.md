# Disable Swap on Kubernetes Nodes

Kubernetes requires swap to be disabled on the nodes to ensure predictable memory management and scheduling behavior.

## 1. Disable Swap Temporarily

Disable all active swap:

```bash
sudo swapoff -a
```

This disables swap immediately but does not survive a reboot.

## 2. Disable Swap Permanently

Check the current `/etc/fstab` configuration:

```bash
cat /etc/fstab
```

Look for a swap entry, for example:

```text
/swap.img none swap sw 0 0
```

Edit the file:

```bash
sudo vi /etc/fstab
```

Comment out the swap entry:

```text
# /swap.img none swap sw 0 0
```

This prevents Ubuntu from enabling swap automatically after a reboot.

> **Note:** Do not blindly delete every line containing `swap`. Commenting out the specific swap entry is safer and preserves the original configuration.

## 3. Verify Swap Is Disabled

Check memory and swap usage:

```bash
free -m
```

Expected result:

```text
Swap:          0          0          0
```

Also verify that no swap devices or files are active:

```bash
swapon --show
```

The command should return no active swap entries.

## 4. SELinux

On AlmaLinux, SELinux may require additional configuration:

```bash
sudo setenforce 0
getenforce
```

Ubuntu 26.04 normally does not use SELinux. Therefore, these commands are **not required** for the standard Ubuntu Kubernetes node preparation.

Ubuntu commonly uses **AppArmor** instead of SELinux.

No SELinux configuration is required for this step.

## Result

Swap is disabled both immediately and permanently, ensuring that it remains disabled after a system reboot.

The Ubuntu-specific preparation differs from AlmaLinux because the SELinux configuration used on AlmaLinux is not required on a standard Ubuntu installation.
