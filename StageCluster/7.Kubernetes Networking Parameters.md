# Kubernetes Networking Parameters

Kubernetes nodes require specific Linux networking parameters to support packet forwarding and container networking.

These settings are applied to **all Kubernetes nodes**.

## 1. Load Required Kernel Modules

Load the required modules:

```bash
sudo modprobe overlay
sudo modprobe br_netfilter
```

Verify that `br_netfilter` is loaded:

```bash
lsmod | grep br_netfilter
```

Configure the modules to load automatically after reboot:

```bash
sudo tee /etc/modules-load.d/k8s.conf <<EOF
overlay
br_netfilter
EOF
```

## 2. Configure Network Parameters

Create the Kubernetes sysctl configuration:

```bash
sudo tee /etc/sysctl.d/k8s.conf <<EOF
net.bridge.bridge-nf-call-iptables = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward = 1
EOF
```

Apply the configuration:

```bash
sudo sysctl --system
```

## 3. Verify Configuration

Verify IPv4 packet forwarding:

```bash
sysctl net.ipv4.ip_forward
```

Expected:

```text
net.ipv4.ip_forward = 1
```

Verify bridge networking parameters:

```bash
sysctl net.bridge.bridge-nf-call-iptables
sysctl net.bridge.bridge-nf-call-ip6tables
```

Expected:

```text
net.bridge.bridge-nf-call-iptables = 1
net.bridge.bridge-nf-call-ip6tables = 1
```

## 4. Troubleshooting

If IPv4 forwarding is still set to `0`, identify which configuration file is overriding the setting:

```bash
grep -R "ip_forward" /etc/sysctl.conf /etc/sysctl.d/ /usr/lib/sysctl.d/
```

If the setting is found in a configuration such as:

```text
/etc/sysctl.d/99-sysctl.conf
```

edit the file:

```bash
sudo vi /etc/sysctl.d/99-sysctl.conf
```

Change:

```text
net.ipv4.ip_forward = 0
```

to:

```text
net.ipv4.ip_forward = 1
```

Apply the configuration again:

```bash
sudo sysctl --system
```

Verify:

```bash
sysctl net.ipv4.ip_forward
```

Expected:

```text
net.ipv4.ip_forward = 1
```

## Result

The required Linux networking parameters are configured and verified on all Kubernetes nodes.

The nodes are now prepared to support Kubernetes container networking and packet forwarding.
