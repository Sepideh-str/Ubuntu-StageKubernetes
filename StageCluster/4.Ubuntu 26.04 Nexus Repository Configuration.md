# Ubuntu 26.04 Nexus Repository Configuration

This step configures Ubuntu 26.04 (Resolute) to obtain operating system packages through the internal Nexus repository instead of accessing public Ubuntu repositories directly.

## 1. Configure Nexus Repositories

Create the APT repository configuration:

```bash
sudo vi /etc/apt/sources.list.d/nexus-ubuntu.list
```

Add the following repositories:

```text
deb [trusted=yes] https://repository.crouseco.com/repository/ubuntu-resolute-proxy/ resolute main restricted universe multiverse
deb [trusted=yes] https://repository.crouseco.com/repository/ubuntu-resolute-update/ resolute-updates main restricted universe multiverse
deb [trusted=yes] https://repository.crouseco.com/repository/ubuntu-resolute-security/ resolute-security main restricted universe multiverse
```

The repositories provide:

* `ubuntu-resolute-proxy` — Main Ubuntu packages
* `ubuntu-resolute-update` — Ubuntu updates
* `ubuntu-resolute-security` — Ubuntu security updates

## 2. Disable Public Ubuntu Repositories

Ubuntu 26.04 uses `/etc/apt/sources.list.d/ubuntu.sources` for its default repositories.

The default configuration points directly to:

```text
http://archive.ubuntu.com/ubuntu/
http://security.ubuntu.com/ubuntu/
```

Rename the file to disable these repositories without deleting the original configuration:

```bash
sudo mv /etc/apt/sources.list.d/ubuntu.sources \
        /etc/apt/sources.list.d/ubuntu.sources.disabled
```

The original configuration can therefore be restored later if required.

## 3. Clean Existing APT Information

Remove the existing APT package indexes:

```bash
sudo apt clean
sudo rm -rf /var/lib/apt/lists/*
```

## 4. Update Package Information

Update the package information:

```bash
sudo apt update
```

APT should now retrieve the package information through the internal Nexus repository.

A successful update should complete without repository errors and report the available packages.

## 5. Verify the Repository Configuration

Check the active APT repositories:

```bash
apt policy
```

The configured repositories should point to:

```text
https://repository.crouseco.com/repository/ubuntu-resolute-proxy/
https://repository.crouseco.com/repository/ubuntu-resolute-update/
https://repository.crouseco.com/repository/ubuntu-resolute-security/
```

The public Ubuntu repositories should no longer be active:

```text
archive.ubuntu.com
security.ubuntu.com
```

## 6. Upgrade the System

After verifying that APT is using Nexus, upgrade the installed packages:

```bash
sudo apt upgrade -y
```

## Result

The Ubuntu 26.04 Kubernetes node is configured to use the internal Nexus repository for operating system packages.

This provides centralized package management and allows the Kubernetes environment to operate within the organization's restricted network architecture without requiring direct access to public Ubuntu repositories.
